# 速度六档分档配色

## Goal

速度读数按六档着色，一眼看出快慢。对标 zcode-speed-panel 的速度分档配色。

## Requirements

- **档位**（tok/s，含下界不含上界）：
  | 档 | 区间 | 色 |
  |---|---|---|
  | 1 | 0–40 | 绿 |
  | 2 | 40–80 | 黄绿 |
  | 3 | 80–160 | 黄 |
  | 4 | 160–240 | 橙 |
  | 5 | 240–320 | 红 |
  | 6 | 320+ | 品红 |
- **实现形态**：`dashboard/index.html` 内共享纯函数 `tierColor(tokPerSec)` + CSS 色板常量；输出同时供文本着色与图形描边使用。
- **应用位置**：
  - 会话总览行卡：实时读数、最近请求速度
  - 近 20 次请求条形图：条形按分档着色
  - 速度趋势图：悬停读数面板数值按分档着色
  - 模型对比：avg / p95 数值着色
  - （预留）mini-speed-page 复用同一函数
- **设计约束——与"估算值=橙色"的现有语义冲突**：估算记录的橙色标注语义必须保留且可区分。方案：估算条形改用斜纹/虚线描边承载"估算"语义，填充色让位给分档色；若实现时判斜纹成本高，允许估算条形退回纯橙、精确条形用分档色，二选一在实现时定，但同一页面内语义不得混淆。
- lite 后台任务速度普遍偏低，同样适用分档（不因 role 改档位）。

## Acceptance Criteria

- [ ] 上述 4 处 UI 位置着色生效且档位一致
- [ ] 估算值与精确值的视觉区分在任何一处都不丢失
- [ ] 单测：`tierColor` 边界值（0 / 40 / 80 / 160 / 240 / 320 及跨界值）
- [ ] 深浅色主题下均可读（跟随仪表盘现有主题变量）
