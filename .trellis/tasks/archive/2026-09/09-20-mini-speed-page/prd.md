# 迷你速度悬浮页 /mini

## Goal

新增 `/mini` 极简路由 + 主仪表盘"迷你窗"按钮，给出常驻小窗形态（大字实时速度 + 今日累计），接近 zcode-speed-panel 的"速度胶囊"体验。桌宠 GIF 不做（素材许可与插件形态都不匹配，明确出范围）。

## Requirements

- **路由**：`GET /mini` 返回独立极简页（无总览/图表/面板），复用现有 SSE 推送与 `/api/state`。
- **页面内容**：
  - 当前口径的实时读数大字（生成中显示速度或脉冲，口径见下）+ 六档分档配色（复用 speed-tier-color 的 `tierColor`）
  - 今日 Σtokens + 调用次数（复用 today-usage-card 的聚合口径；若该子任务未完成则先显示会话本轮累计，完成后再切换——实现顺序上本任务排其后，正常情况已可用）
  - 最近活跃会话短 ID 一行（多会话时列出，点击切换聚焦）
- **聚焦口径**：不引入独立聚焦逻辑。默认跟随主页面聚焦状态：`?session=<id>` URL 参数显式指定，或与主页面共享 localStorage 键。二选一在实现时定，写入实现说明。
- **小窗**：主仪表盘头部加"迷你窗"按钮，`window.open('/mini', ..., 'popup=yes,width=320,height=180')`；页面 `<meta>` 适配窄窗。
- **风格**：跟随仪表盘现有主题变量，不另起一套配色（六档色除外）。

## Acceptance Criteria

- [ ] 直接访问 `http://127.0.0.1:<port>/mini` 可用，SSE 断线自动重连（与主页同等待遇）
- [ ] 主页面"迷你窗"按钮打开 320×180 popup 窗，内容正确、无横向滚动
- [ ] 实时读数着分档色，与主页面同数值同色
- [ ] README 安装/功能段落提及迷你窗入口
- [ ] 现有页面与测试零回归

## Notes

- 中轻量任务，PRD-only。
- 依赖：speed-tier-color（tier 函数）、today-usage-card（今日聚合 API/字段）。排序在其后。
- 实时读数的"生成中"表现受限于 Hook 协议（无流式事件），若 realtime-speed-spike 结论落地则后续升级，本任务先用现状语义（生成中脉冲 + 最近完成速度）。
